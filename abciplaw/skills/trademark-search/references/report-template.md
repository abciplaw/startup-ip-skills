# 선행상표 검토 보고서 양식

파일명: `00_선행상표검토.md`. 사용자(상표 비전문가)가 가장 먼저 읽는 파일이다. 5단계에서 검색 결과를 판단한 뒤 작성하고, 8절은 6단계(ABC 검토 의뢰 안내)에서 채운다.
`<!-- -->` 안의 작성 요령은 결과 파일에서 지운다. 해당 내용이 없으면 절을 지우지 말고 「없음」 또는 `[확인 필요]`로 둔다. 문장은 짧고 쉽게, 법률 용어는 처음 나올 때 풀어 쓴다.

| 항목 | 내용 |

| ABC 관리번호 | <사용자가 알려 준 경우만 적고, 아니면 이 행을 지운다> |

| 결론 (예비 의견) | **출원 진행 검토 가능 / 보완 후 출원 검토 / 이름 재검토 권장** |

> 이 결론은 사용자가 직접 검색한 범위 안의 예비 의견이며, 등록 여부에 대한 판단이 아닙니다. 출원 여부와 지정상품 범위는 변리사와 상담해 정하십시오.
