# 등록이 어려운 이름 — 식별력과 그 밖의 거절 이유 점검

상표는 「이 상품은 이 회사 것」이라고 구별해 주는 표시여야 등록된다. 이 힘을 **식별력**이라고 한다. 상품을 그대로 설명하는 말이나 누구나 쓰는 흔한 말은, 같은 이름의 선행상표가 하나도 없어도 등록이 거절된다(상표법 제33조). 다른 사람도 그 말을 자유롭게 써야 하기 때문이다.

이 점검은 선행상표 검색보다 먼저 한다. 사업자가 가장 많이 놓치는 부분이고, 여기서 걸리면 검색을 아무리 잘해도 소용이 없다. 모든 판단은 **예비 의견**이다. 같은 말도 지정상품에 따라 결론이 달라진다는 점을 늘 함께 적는다(「APPLE」은 사과에는 설명하는 말이지만 컴퓨터에는 아니다).

표의 예시는 설명을 위한 것이다. 실제 사건의 결론과 다를 수 있고, 지정상품과 시기에 따라 판단이 바뀐다.

## 1. 식별력이 없거나 약한 유형 (상표법 제33조 제1항)

상표를 부분으로 나눈 뒤 부분마다, 그리고 전체로 아래에 해당하는지 본다.

| 유형 | 쉬운 설명 | 지어낸 예 (지정상품) |
|---|---|---|
| 보통명칭 | 그 상품을 부르는 일반적인 이름 | 「콘칩」(과자), 「SOFTWARE」(소프트웨어) |
| 관용표장 | 처음엔 특정 회사 것이었어도 업계에서 누구나 붙여 쓰게 된 표시 | 「정종」(청주), 「깡」(과자) |
| 성질표시 | 산지·품질·원재료·효능·용도·수량·모양·가격·만드는 법·쓰는 법·시기를 그대로 알리는 말 | 「촉촉크림」(보습 크림), 「FAST DELIVERY」(배달 서비스), 「유기농」(식품), 「프리미엄」·「BEST」(모든 상품) |
| 현저한 지리적 명칭 | 널리 알려진 나라·도시·명소 이름이나 그 약어 | 「서울」, 「제주」, 「NEW YORK」 |
| 흔한 성·명칭 | 흔한 성씨, 흔한 상호 꼴 | 「김씨네」, 「박가」, 「○○상사」, 「CO.」 |
| 간단하고 흔한 표장 | 글자 한두 개, 흔한 숫자, 단순한 도형 | 「A」, 「K1」, 「123」, 원·네모 하나 |
| 그 밖에 구별이 안 되는 것 | 구호·인사말·유행어, 흔한 인터넷 주소 꼴 | 「잘 먹겠습니다」, 「www.○○.com」 꼴, 「핫딜」 |

판단 요령:
- **바로 떠오르면 성질표시, 한 번 생각해야 하면 암시.** 상품을 보고 그 말이 곧바로 「품질·효능을 말하는구나」로 읽히면 등록이 어렵다. 한 단계 상상을 거쳐야 연결되면(암시적 표장) 등록될 수 있다. 예: 보습 크림에 「촉촉크림」은 어렵고, 「아침이슬」은 암시에 가깝다.
- **외국어도 같다.** 국내 일반 수요자가 뜻을 쉽게 아는 영어(「FRESH」, 「SMART」, 「CARE」)는 한국어와 똑같이 본다. 철자를 살짝 바꿔도(「FRESHH」, 「Smartt」) 같은 말로 읽히면 마찬가지다.
- **약한 말끼리 합쳐도 약하다.** 「PREMIUM」+「CLEAN」처럼 둘 다 약하면 합쳐도 대개 약하다. 반면 약한 말에 만든 말을 더하면(「CLEAN」+「VORA」) 전체로는 식별력이 생길 수 있다. 다만 그 상표의 힘은 만든 말 쪽에 있다(선행상표 판단 때도 중요 — similarity-guide 2절).
- **로고로 감싸면 해결되나?** 글자가 성질표시여도 로고(도안)가 특이하면 전체로 등록될 수 있다. 그러나 그 등록은 로고 모양에 대한 것이고, 「촉촉크림」이라는 글자 자체를 남이 못 쓰게 하는 힘은 거의 없다. 사용자에게 이 점을 꼭 알린다.
- **오래 써서 유명해진 경우**(상표법 제33조 제2항)에는 예외가 있지만 입증이 어렵다. 새로 출원하는 사업자에게는 기대하지 말라고 안내한다.

## 2. 식별력과 별개로 등록이 안 되는 이유 (상표법 제34조 — 자주 걸리는 것만)

| 경우 | 쉬운 설명 |
|---|---|
| 국가·공공기관 표시 | 국기, 국제기구·공공기관 이름·표장과 같거나 비슷한 것 |
| 유명한 사람·회사 이름 | 널리 알려진 남의 이름·상호·예명 등을 그 사람 동의 없이 넣은 것 |
| 이미 등록된 남의 상표 | 먼저 출원해 등록된 남의 상표와 비슷하고 상품도 비슷한 것(제34조 제1항 제7호) — 선행상표 검색으로 확인하는 부분 |
| 널리 알려진·유명한 상표 | 등록 여부와 관계없이 수요자에게 널리 알려진 남의 상표와 혼동되는 것. 유명한 상표는 상품이 달라도 걸릴 수 있다 |
| 품질 오인 | 상품의 품질을 오해하게 하는 것(예: 국산 상품에 「SWISS」, 유기농이 아닌 상품에 「유기농」) |
| 부정한 목적 | 국내외에서 남이 쓰는 상표를 먼저 출원해 가로채려는 것 |
| 공공질서 | 사회 질서·도덕에 어긋나거나 특정 집단을 비하하는 것 |

이 중 「유명한 상표」는 키프리스 검색에서 상품이 달라 걸러지기 쉽다. 사용자의 이름이 널리 알려진 브랜드와 같거나 비슷하면(예: 유명 브랜드에 한 글자 더한 이름) 상품이 달라도 「주의」로 적는다.

또 하나: 먼저 출원된 남의 상표는 아직 등록 전이어도 장애가 된다(선출원, 상표법 제35조). 그래서 검색 때 출원 중인 상표도 본다.

## 3. 결과 쓰는 법

부분별로 나눠 한 표로 쓴다.

| 부분 | 뜻·읽기 | 지정상품과의 관계 | 판단 |
|---|---|---|---|
| <부분 1> | | | 식별력 있음 / 약함 / 없음 |
| <부분 2> | | | |
| **전체** | | | **문제 적음 / 주의 / 등록 어려움** |

- **문제 적음**: 만든 말이거나 상품과 관계없는 말. 「그래도 선행상표가 있으면 등록이 안 될 수 있으니 검색은 꼭 한다」고 덧붙인다.
- **주의**: 일부가 약하거나, 암시와 설명 사이에 있거나, 지정상품에 따라 결론이 갈린다. 어느 지정상품에서 문제가 되는지 적는다.
- **등록 어려움**: 전체가 성질표시·보통명칭·흔한 말에 해당한다. 보완 방향을 적는다: 만든 말을 더하거나 바꾸기, 상품과 관계없는 말 쓰기, 로고 결합의 한계(위 1절).

사용자 말투로 한두 줄 요약을 붙인다. 예: 「‘촉촉’은 보습 크림의 효과를 그대로 말하는 단어라 혼자서는 등록이 어렵습니다. 뒤에 붙인 ‘루미’가 이 상표의 힘이 되는 부분입니다.」
