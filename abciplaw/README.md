# 특허 포트폴리오 발굴 스킬 (Patent Portfolio Discovery Skill)

**AI 에이전트와 개발 중인 프로젝트에서, 변리사가 하던 방식으로 회사의 특허 포트폴리오를 발굴하고 설계합니다.**

[English](README.en.md)

개발하다 보면 「이건 특허를 내야 하지 않을까?」 싶은 순간이 옵니다. 그런데 무엇을 특허로 할지, 그게 특허가 될 만한지, 몇 건을 어떤 순서로 어느 나라에 내야 할지, 투자자에게는 어떻게 설명할지부터 막히는 경우가 많습니다. 특허는 많이 내는 것보다 **사업에 맞게** 내는 것이 중요합니다.

이 스킬은 AI·소프트웨어·반도체 장비 등 딥테크 분야에서 다년간 특허 업무를 하고, 스타트업 투자와 기술특례상장 평가에도 참여해 온 한국 변리사(ABC특허법률사무소)가 스타트업·중소기업의 특허 포트폴리오를 설계할 때 쓰는 방식을 AI 에이전트용 지침으로 옮긴 것입니다. 개발을 함께 해 온 에이전트(Claude Code, Codex, Gemini CLI 등)에게 「특허 포트폴리오 발굴해줘」라고 하면, 에이전트가 코드·문서·수정 이력을 읽고 몇 가지를 여쭌 뒤 다음을 합니다.

1. **시장과 고객에서 시작** — 고객이 왜 우리 제품을 고르는지, 경쟁사가 가장 따라 하고 싶어 할 차별점이 무엇인지부터 봅니다.
2. **사업을 기술로 쪼개기** — 차별점을 기술 요소로 나누고, 코드에서 찾은 기술과 맞춰 **제품–기술 지도**를 만듭니다.
3. **특허성 필터** — 특허 대상인지, 이미 공개되지 않았는지, 쉽게 떠올릴 수 있는 것은 아닌지, 권리로 쓸모가 있는지, 영업비밀이 나은지 봅니다. 결과는 **출원 권장 / 보강 후 검토 / 출원 비권장**이고, 약한 후보는 어떻게 하면 강해지는지 적습니다.
4. **포트폴리오 설계** — 발명을 **원천·핵심 / 응용 / 신사업·해외** 층에 놓고 빈 칸을 찾아 추가 발굴을 제안합니다. 회사의 성장 단계(초기·성장·성숙)에 맞는 할 일, 출원 순서와 예산 우선순위, 해외 출원 가안, 특허와 영업비밀·디자인·상표를 함께 쓰는 방법, **투자·IR용 특허 설명 초안**까지 정리합니다.
5. **기술설명서** — 출원할 만한 발명마다 변리사가 곧바로 명세서 작성에 쓸 수 있는 문서(발명신고서를 대신하는 문서)를 씁니다.
6. **의뢰 준비(원할 때만)** — 결과를 확인하신 뒤 원하시면 에이전트가 결과 폴더를 압축해 드립니다. 메일로 직접 보내 주시면 됩니다. 에이전트가 대신 보내지는 않습니다.

예시는 [examples/patent-portfolio/](../examples/patent-portfolio/)에 있습니다(반도체 세정 장비 소프트웨어를 가정한 가상의 프로젝트).

상표 출원을 준비하신다면 같은 플러그인의 [선행상표 검색 스킬](#선행상표-검색-스킬-trademark-pre-filing-search)을 쓰세요.

## 사용

개발 중인 프로젝트 폴더에서 에이전트를 열고 「특허 포트폴리오 발굴해줘」라고 하세요. 개발하던 대화 창에서 바로 하면 그동안 나눈 대화(어떤 문제를 어떻게 풀었는지)까지 반영합니다. 사업계획서나 IR 자료가 저장소에 있으면 함께 읽습니다. ABC특허법률사무소 고객사는 관리번호를 함께 알려 주세요.

에이전트가 발명 목록과 예비 판정을 보여 드린 뒤 질문을 한 번에 몇 가지 드립니다(고객이 왜 우리 제품을 고르는지, 경쟁사, 이미 공개했는지, 진출하려는 나라, 측정한 성능 수치 등). 이 답이 특허성과 포트폴리오 판단의 근거가 됩니다. 답하면 프로젝트 폴더 안에 `patent-portfolio` 폴더가 생깁니다.

| 파일 | 내용 |
|---|---|
| `00_포트폴리오요약.md` | 제품–기술 지도, 후보별 판정, 포트폴리오 지도와 빈 칸, 추가 발굴 제안, 단계별 할 일과 출원 순서·예산, 해외 가안, IP-Mix, 투자·IR용 설명 초안, 공개 여부와 일정 |
| `발명01_….md` … | 출원 권장·보강 후 검토 발명마다 한 파일: 해결하려는 문제, 핵심 아이디어, 특허성 예비 검토, 포트폴리오에서의 역할, 구성, 처리 흐름, 기준값, 대안, 효과, 공개 여부 |
| `ABC의뢰_<날짜>.zip` | 검토를 원하신 경우 메일로 보내실 압축 파일 |

## ABC특허법률사무소 검토 의뢰

결과를 알려 드린 뒤 에이전트가 검토를 원하시는지 묻습니다. 원하시면 의뢰에 적을 정보(회사명, 담당자, 연락처 등)를 여쭙고 결과 폴더를 압축해 드립니다. 내용을 확인하신 뒤 메일(abcip@abcip.co.kr)로 보내 주세요. 요약서만 먼저 보내 상담을 받으셔도 됩니다.

에이전트는 메일 발송, 업로드, 외부 접속을 하지 않습니다. 보내는 것은 언제나 사용자가 직접 합니다.

## 꼭 알아 두실 것

- **결과물을 공개하지 마세요.** 공개 저장소, 이 저장소의 이슈, 블로그, 커뮤니티, AI 대화 공유 링크에 올리면 그 자체로 공개가 되어 특허를 받기 어려워질 수 있습니다. 결과 폴더는 git에 올라가지 않도록 자동 설정됩니다.
- **출시·발표·IR·정부 과제 발표 전에 출원하세요.** 한국·미국은 공개 후 1년 안에 예외를 주장할 수 있지만, 유럽·중국 등은 예외가 매우 좁습니다.
- **판정과 제안은 에이전트의 예비 의견입니다.** 선행 기술 조사를 하지 않은 상태에서 변리사의 판단 순서를 따라 본 것이며, 특허 등록 가능성을 판단한 것이 아닙니다. 출원 여부, 국가, 일정, 예산은 변리사와 상담해 정하세요.
- **에이전트는 밖으로 보내지 않습니다.** 웹 검색·선행조사·경쟁사 조사·업로드·메일 발송을 하지 않도록 지시되어 있고, 예외가 없습니다. 결과 문서에는 소스 코드 원문, 비밀번호·키, 내부 서버 주소, 개인정보를 넣지 않습니다.
- **설치가 걱정되시면** [보안 안내](../SECURITY.md)를 먼저 읽어 보세요. 이 플러그인에는 실행되는 코드가 없고(글 파일뿐), 설치 전에 5분이면 직접 확인할 수 있습니다. 설치 없이 [PROMPT.md](PROMPT.md)만 써도 결과는 같습니다.
- 이 저장소의 내용은 법률 자문이 아닙니다.

## 선행상표 검색 스킬 (Trademark Pre-filing Search)

같은 플러그인에 상표 출원을 준비하는 분을 위한 스킬이 하나 더 들어 있습니다. 상표 전문가가 아니어도 쓸 수 있도록 쉬운 말로 안내합니다. 「선행상표 검색해줘」라고 하면 에이전트가

1. **상표와 사업을 한 번에 여쭙니다** — 이름, 읽는 법, 뜻, 붙일 상품·서비스, 판매 방식, 사용 여부, 진출 국가.
2. **이름 자체가 등록이 어려운지 먼저 봅니다(식별력)** — 상품을 설명하는 말, 흔한 말, 지명처럼 선행상표가 없어도 거절되는 이름인지.
3. **검색 계획을 만듭니다** — 지정상품과 상품류를 정리하고, 유사군코드 찾는 법을 알려 드리고, 발음·철자·뜻을 바꾼 검색어 10~25개와 키프리스(kipris.or.kr) 따라하기를 `trademark-search/01_검색계획.md`에 씁니다.
4. **직접 검색하신 결과를 판단합니다** — 결과를 폴더에 넣거나 대화에 붙여 넣으시면, 선행상표마다 상품 유사와 외관·칭호·관념 유사를 따로 보고 위험(높음 / 주의 / 낮음)과 피하는 방법을 `00_선행상표검토.md`에 정리합니다.
5. **의뢰 준비(원할 때만)** — 특허 스킬과 같이 결과 폴더를 압축해 드리고, 보내는 것은 직접 하십니다.

| 에이전트 | 실행 |
|---|---|
| Claude Code (위와 같이 설치) | `/abciplaw:trademark-search` 또는 「선행상표 검색해줘」 |
| Gemini CLI | `gemini skills install https://github.com/abciplaw/startup-ip-skills.git --path abciplaw/skills/trademark-search` 다음 「선행상표 검색해줘」 |
| OpenAI Codex | `abciplaw/skills/trademark-search` 폴더를 `~/.agents/skills/`에 복사한 뒤 `$trademark-search` |
| 그 밖의 에이전트·채팅 앱 | 「[PROMPT-trademark-search.md](PROMPT-trademark-search.md)를 읽고 그대로 진행해줘」, 또는 파일을 올리거나 내용을 붙여 넣기 |

개발 프로젝트가 없어도 됩니다. 아무 폴더에서나 실행하면 그 안에 `trademark-search/` 폴더가 생기고, 파일을 쓸 수 없는 채팅 앱에서는 결과를 대화로 보여 드립니다.

**왜 에이전트가 직접 검색하지 않나요?** 출원 전의 상표는 아직 보호받지 못합니다. 쓰려는 이름이 미리 알려지면 다른 사람이 먼저 출원할 위험이 있고, 에이전트가 웹에서 모은 결과는 빠지거나 틀린 것이 섞여도 알아채기 어렵습니다. 그래서 검색은 직접 하시고, 에이전트는 무엇을 어떻게 검색할지와 결과가 무슨 뜻인지를 맡습니다. 에이전트는 검색 결과에 없는 선행상표를 지어내지 않습니다.

꼭 알아 두실 것:
- 판단은 **예비 의견**입니다. 등록 여부에 대한 판단이 아니며, 직접 검색하신 범위 안에서만 의미가 있습니다.
- 상표는 **먼저 출원한 사람**이 우선입니다. 쓰기로 정한 이름은 출원을 미루지 마세요.
- 등록하지 않고 쓰이기만 하는 이름(가게, 온라인몰, 앱, SNS), 회사 이름·도메인, 해외 상표는 이 검색에 잡히지 않습니다. 로고(그림) 부분 검색은 변리사에게 맡기시는 편이 낫습니다.
